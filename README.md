# Gumroad Revenue Copilot Prototype

Build-ready handoff for a Gumroad open-source competition prototype.

Start here:

- [prototype.md](prototype.md)
- [DEMO.md](DEMO.md)

Run the local static demo:

```bash
npm run demo
```

Then open `http://localhost:8080/`.

Core idea:

Gumroad already shows creators what happened. Revenue Copilot tells them what to do next by turning product analytics into evidence-backed revenue actions.
